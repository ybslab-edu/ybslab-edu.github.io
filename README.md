# 九年級資訊科技 課堂活動網站

每週一個 45 分鐘課堂活動。學生免登入，填班級座號後開始，過關後產生成績碼；老師在教師專區貼上成績碼，依週次與班級匯出 Excel。

## 網站結構

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 首頁，依 `assets/weeks.js` 列出每週活動 |
| `w01/` … | 每週活動頁，一週一個資料夾 |
| `teacher/` | 教師成績彙整（資料只存在老師自己的瀏覽器） |
| `assets/weeks.js` | 週次清單：標題、主題、關卡名稱 |
| `assets/codec.js` | 成績碼編碼與解碼，所有週次共用 |

## 第一次上線（GitHub Pages）

1. 把這個資料夾推到 GitHub 儲存庫的 `main` 分支。
2. 到儲存庫的 Settings → Pages，Source 選「Deploy from a branch」，分支選 `main`、資料夾選 `/ (root)`，按 Save。
3. 約一分鐘後，網址會出現在同一頁，格式為 `https://帳號.github.io/儲存庫名稱/`。

## 每週新增一課

1. 新增資料夾 `w02/`，放入 `index.html`，頁面開頭設定 `const WEEK=2;`，並載入 `../assets/codec.js`。
2. 在 `assets/weeks.js` 最後加一筆，`rounds` 的順序要和活動頁的關卡順序一致（最多 6 關）。
3. 推上 `main`，網站自動更新。

## 成績碼

- 16 碼（例如 `E2K5-H7W2-FZFX-3M1A`），包含班級、座號、週次、各關是否過關、各關嘗試次數、時間與檢查碼。
- 學生改動任何一碼都會驗證失敗。
- 第 1 週在 Claude 試跑時發出的 13 碼舊格式，教師專區仍可讀取。
- 不含姓名或其他個資。
