# 次元交會動漫／遊戲展：志工招募故事設定

## 委託與角色

星港策展團隊籌辦「次元交會動漫／遊戲展」。招募窗口阿岑請你設計報名表，排班窗口小洛接手回覆清理，成果窗口阿禾負責把統計成果整理成可交付檔案。人物僅作故事中的工作角色，不收集學生姓名。學生頁以「你」稱呼接案者，不使用學校意象。

三週共用職務：入口引導、遊戲體驗、舞台支援。時段：上午場 09:00–12:00、下午場 13:00–17:00；可複選到場時段，第一志願職務只能選一項。比較圖可依國中組／高中組分組；不同組最熱門職務可能不同，不能把一組的結論套到所有人。

招募資料僅供排班、必要培訓與活動當天緊急聯繫，由招募窗口使用，活動結束 30 天後刪除。須先說明用途並取得同意，拒絕者直接結束；未滿 18 歲者先完成家長同意確認。這是本活動的招募規格，並非通用法規判定。

## 欄位與資料界線

| 欄位 | 目的與設定 |
| --- | --- |
| 報名代號 | 短文字、必填；後續用合成代號 V1 等辨識列，不使用姓名 |
| 組別 | 圖表比較用國中組／高中組；僅在需要比較時納入 |
| 第一志願職務 | 三選一，選擇題、必填 |
| 可到場時段 | 上午／下午，核取方塊、必填 |
| 服務期待程度 | 線性刻度，依當組要求設定範圍與必填 |
| 各職務操作熟悉度 | 每列職務選一個程度，單選方格；有培訓安排需求才收 |
| 緊急聯絡人及聯絡方式 | 僅為活動當天安全所必需；教材只評估欄位是否必要，不輸入任何真實內容 |
| 同意／年齡分流／家長同意確認 | 先告知再取得允許；使用選擇題分流，未取得所需同意者結束 |
| 送出時間 | 系統產生；後續去重時不把時間差當成不同內容 |

不收集家庭收入、社群帳號密碼、與招募無關的角色生日。後續清理、分析、匯出與壓縮素材均使用合成資料，不包含緊急聯絡內容、真實名單或帳密。資料格式及雲端路徑沿用既有規格。
