# 成績自動上傳：設定步驟

學生用學校 Google 帳號登入活動頁，系統依老師的名單自動認出班級、座號、姓名；每過一關，紀錄自動寫進老師的 Google 試算表。
需要老師用**學校帳號**做兩件事（約 20 分鐘），拿到兩個值後填進網站的 `assets/login.js` 就會啟用。
兩個值都留空時，活動頁維持原本的「班級座號＋成績碼」。

## A. 建立登入用的用戶端 ID（Google Cloud）

1. 用學校帳號開 <https://console.cloud.google.com/>，建立一個專案（名稱例如 `YBS Lab`）。
   若顯示沒有權限建立專案，代表學校管理員有限制，請資訊組協助。
2. 左側選單「API 和服務」→「OAuth 同意畫面」（新版介面叫「Google Auth Platform」）。
   - 使用者類型選 **內部**：只有 `@cgjh.hcc.edu.tw` 帳號能登入，也不需要 Google 審查。
   - 應用程式名稱填 `YBS Lab`，支援電子郵件填自己的學校信箱，其餘留空，儲存。
3. 「憑證」→「建立憑證」→「OAuth 用戶端 ID」。
   - 應用程式類型：**網頁應用程式**。
   - 已授權的 JavaScript 來源：加入 `https://ybslab-edu.github.io`。
   - 建立後複製「用戶端 ID」（結尾是 `.apps.googleusercontent.com`）。

## B. 建立成績試算表與 Apps Script

1. 用學校帳號建立一個 Google 試算表，命名例如 `YBS Lab 成績`。
2. 「擴充功能」→「Apps Script」，刪掉預設內容，貼上本資料夾 `Code.gs` 的全部內容。
3. 把第一段的 `CLIENT_ID = ''` 填上 A 拿到的用戶端 ID，按儲存。
4. 上方函式選單選 `setup`，按「執行」（第一次會要求授權）。試算表會出現「名單」「成績總表」「上傳紀錄」三個工作表。
5. 打開「名單」工作表，從第 2 列起貼上學生名單，四欄依序是：**學校帳號｜班級｜座號｜姓名**（例如 `s1100123@cgjh.hcc.edu.tw｜901｜12｜王小明`）。
   - 帳號大小寫、前後空白都沒關係；轉學、換座號時直接改這張表就好。
   - 名單只存在你的試算表裡，不會放到公開網站上。
6. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**任何人**（實際寫入前會向 Google 驗證是不是本校帳號，外人寫不進來）
   - 按「部署」，依畫面授權（存取試算表、連線到外部服務），複製「網頁應用程式網址」（結尾是 `/exec`）。
   - 如果沒有「任何人」這個選項，是學校管理員關掉了，請資訊組開放。

## C. 交給網站

把**用戶端 ID** 和 **`/exec` 網址**填進 `assets/login.js` 的 `clientId`、`endpoint`（或交給協作的 Claude 處理）。
這兩個值都不是密碼，放在公開網站上沒有關係。

第一次有學生上傳後，試算表會自動出現兩個工作表：

| 工作表 | 內容 |
| --- | --- |
| 名單 | 老師貼上的學生名單；學生登入後看到「你是 901 班 12 號 王小明，對嗎？」，按「對，開始」就能做活動 |
| 成績總表 | 每位學生每個活動一列：學期週次、活動、班級、座號、姓名、學校帳號、各關（✓ 與嘗試次數）、過關數、最後更新 |
| 上傳紀錄 | 每過一關一列的原始紀錄，含時間與成績碼，可用來比對 |

## 之後要注意

- 修改 `Code.gs` 後，要到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」再部署，網址才不會變。
- 過關是在學生的瀏覽器判定的，懂程式的學生理論上能偽造**自己**的過關紀錄；但只能用自己的帳號、改不到別人的。「上傳紀錄」保留時間與嘗試次數，可以用來抽查。
- 班級座號以「名單」為準：名單上的學生不用填、也改不了。本校帳號但不在名單上的學生，會請他自己填班級座號，成績總表的姓名欄標「（不在名單）」，方便你補名單。
- 學生用的若是一般 `@gmail.com` 帳號而不是學校網域帳號：A 的同意畫面改選「外部」並按「發布應用程式」，`Code.gs` 的 `DOMAIN` 與網站 `assets/login.js` 的 `domain` 都改成 `''`。這時只有名單上的帳號能使用。
- 姓名只存在老師的試算表，只在學生本人登入後顯示給他自己看，不會存在學生的電腦或公開網站上。
- 學生登入憑證約 1 小時後過期，畫面會提示重新登入；沒上傳成功的紀錄會先存在那台電腦，登入後自動補傳。
